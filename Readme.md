# Portfolio

Ce projet est un site vitrine personnel permettant de présenter mon profil,
mes compétences et mes projets en tant que développeur web débutant.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Docker
- Git & GitHub

---

## Installation (sans Docker)

1. Cloner le dépôt :

git clone https://github.com/cc-didic/Portfolio-Front-end.git
Ouvrir le fichier index.html dans un navigateur.
